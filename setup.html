⚙️ Set up your class website

Hi, Mrs. Pitts! The website already works in preview mode. Follow these steps once to send every score to your own Google Sheet. It takes about 15 minutes.

1. Sheet2. Apps Script3. Deploy4. Paste URL5. GitHub PagesStudentsPasscodeHelp
1

📗 Make a Google Sheet

  1. Go to sheets.google.com. Sign in with your school Google account.
  2. Click Blank spreadsheet.
  3. Name it at the top left, like Pitts Class Data.

You own this sheet. Student scores go only here.

2

🧩 Add the Apps Script

  1. In your sheet, click Extensions then Apps Script.
  2. A new tab opens with a little bit of code. Select all of it and delete it.
  3. Open the file Code.gs from the website folder. Copy everything in it.
  4. Paste it into the Apps Script page. Click 💾 Save.
  5. At the top, choose setupTabs in the function menu and click ▶ Run. Allow access when Google asks. This builds every tab for you: 🏆 Class Overview (class averages for Reading, Writing, Math, History, Science and each student’s scores), ⭐ Mastery, ⚡ Fluency, 📋 All Scores, and one tab for every activity. Everything fills in automatically when students finish work.
  6. Near the top you will see var PASSCODE = "pitts2026";. You can change the word inside the quotes. Write it down.
3

🚀 Deploy it as a web app

  1. Click the blue Deploy button, then New deployment.
  2. Click the ⚙️ gear next to “Select type” and pick Web app.
  3. Set Execute as: Me
  4. Set Who has access: Anyone
  5. Click Deploy. Click Authorize access, pick your account, then Advanced → Go to project (unsafe) → Allow. (This is normal for your own script.)
  6. Copy the Web app URL. It ends with /exec.

💡 “Anyone” lets students send scores without signing in to Google. Only you can open the sheet. The dashboard needs your passcode to read data.

4

🔗 Paste the URL into k3-config.js

Open k3-config.js and find scriptUrl. Paste your URL between the quotes:

scriptUrl: "https://script.google.com/macros/s/AKfy.../exec",

Also make sure the passcode matches the one in Code.gs:

teacherPasscode: "pitts2026",
5

🌐 Put the website on GitHub Pages

  1. Go to github.com and sign in (or make a free account).
  2. Click + (top right) → New repository. Name it something like pitts-class. Choose Public. Click Create repository.
  3. Click uploading an existing file. Drag in all the website files: index.html, setup.html, k3-style.css, k3-config.js, k3-engine.js, and every k3-…js content file. (You do not need to upload Code.gs.) Click Commit changes.
  4. Go to Settings → Pages. Under “Branch”, pick main and / (root). Click Save.
  5. Wait 1 to 2 minutes. Your website link appears at the top of that page, like https://yourname.github.io/pitts-class/.

💡 Test it: sign in as a student, finish an activity, then look at the 🏆 Class Overview and 📋 All Scores tabs in your sheet. Then open 🍎 Teacher → Dashboard → ☁️ Load from Sheet.

🧑‍🎓 The class list (students sign in with first + last name)

Students sign in by typing their first name and last name. Every score is saved under that name in your Google Sheet. Capital letters, accents, and extra spaces don’t matter.

🔒 Privacy: k3-config.js can be seen by anyone who opens the website code, so don’t type real full names there. Use the Name Code Maker below instead. It turns each name into a secret code. The website can check a typed name against the code, but nobody can read the names from it. Real names only go to your private Google Sheet.

🔐 Name Code Maker

Type one student per line (first and last name), then press Make codes. This all happens on your computer, and nothing is sent anywhere.

students: [
]
  1. Copy the result and paste it over the students: [ … ] part of k3-config.js on GitHub (✏️ pencil → paste → Commit changes).
  2. Now only names on your list can sign in. If a student types a name that isn’t on the list, Elvis asks them to check their spelling.
  3. Keep your typed list somewhere private (like a Google Doc) so you can add students later.
  4. While the list is empty, the site accepts any name. That’s handy for testing, but typos can make extra rows in your sheet.

🔑 Change the teacher passcode

  1. In k3-config.js, change teacherPasscode: "pitts2026".
  2. In Apps Script, change var PASSCODE = "pitts2026"; to the same word. Save.
  3. In Apps Script click Deploy → Manage deployments → ✏️ → Version: New version → Deploy. The URL stays the same.

The passcode is a light lock to keep students out of the teacher area. Anyone who reads the website code can find it.

✏️ Other things you can change in k3-config.js

  • announcements: messages on the home page. One per line, in quotes, with commas.
  • mascot: an emoji for the logo, like "🦅".
  • goals.mathFactsPerMin: the fact sprint goal line (now 30).
  • goals.readingWCPM: words correct per minute goals. They are set to the Hasbrouck & Tindal (2017) grade 3, 50th percentile national norms: fall 83, winter 97, spring 112.

🛟 Help

  • Scores do not show in the sheet? Check that scriptUrl ends with /exec and that “Who has access” is Anyone.
  • Dashboard says “Wrong passcode”? The passcode in Code.gs and k3-config.js must match. Deploy a new version after changing Code.gs.
  • No internet? Scores are saved on the device and sent later.
  • Mastery tab rebuilds itself after every score. You can also use the sheet menu 🍎 Class Website → Rebuild Mastery tab.
  • Try it without a sheet: in 🍎 Teacher → Dashboard, click 🧪 Show demo data.
